# Our own web index for AI, with sources

askFinz runs its own real-time index of the web — fed by the browser extension, the desktop app, askFinz OS devices, indexer machines and partner sites.

## Key points

### Start here

Think of it as askFinz's library — a working copy of the useful web that it keeps, reads and maintains itself.

### Where it comes from

A conventional search index has one way in: a crawler on a server somewhere, working through a list. askFinz has six.

### What isn't in it

Reading “from everywhere” means the public web is reached from many directions — not that anything private is collected along the way. This index is built from pages that are already published for anyone to read.

### The whole picture

A computer you already own can take a share of the reading, using only what it can spare. Nothing reformatted, and one line to take it back off again.

### How a page becomes an answer

A traditional index rebuilds on a schedule, so what it knows is always a little out of date. Here the last step happens the moment the first one does — a page seen now is answerable now.

### Live · on-demand indexing

Most search engines make you wait days to be noticed. Here you can hand a page straight over — and it's searchable while you're still looking at the screen.

### Live · search performance

The whole index is searched on every question. These figures aren't from a slide — they're read from the engine while you look at them.

### Live · what's in there

Research papers, reports, filings and slide decks hold some of the most useful knowledge there is. Most search engines will happily link to a PDF without ever having read it.

### Live · the dedicated machines

Alongside the surfaces that read as part of normal use, a set of computers is given over to the job entirely — some lent by people with capacity to spare, some installed with partners. These are their figures, live.

### Built for the whole web

Most of the web is easy. The interesting part is the web that isn't — documents, app-built pages, and sites designed to keep automated tools out.

## Frequently asked

### What makes this different from a normal search index?

Timing and depth. Pages become searchable the moment they're read rather than after a scheduled rebuild, and what's stored is the meaning of the page rather than a list of keywords — so an AI can reason over it instead of just matching words.

### Where does the computing power come from?

From askFinz's own index servers, plus every surface askFinz runs on — the browser extension, the desktop app, devices running askFinz OS — and a set of machines dedicated to the job, some lent by people with capacity to spare and some installed with partners.

### How fresh is it really?

The live figures on this page are read from the running system every few seconds. Pages are indexed as they're read, and popular sources are revisited rather than being read once and forgotten.

### Can I get my own site in?

Public pages are reached in the normal course of crawling. To be read directly and kept fresh with priority, become a verified domain partner.

### How is it kept clean?

Pages are checked before they go in: dead ends and unsafe sites stay out, and every page is filed in the right collection. Sonar, the first model built at askFinz Model Fab, is coming to that job, working alongside the checks already in place.
