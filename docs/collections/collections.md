# Search collections: every library in the web index

The askFinz index is kept as separate collections — research, law, standards, patents, news and more — each filed by what it is, not as loose web pages.

**Canonical page:** [https://askfinz.com/collections](https://askfinz.com/collections)

## Key points

### What's held, and what it's for

30 collections, a page each — filed by what each one holds rather than by where it was found. Filing each page from the open web on the right shelf is the job Sonar, askFinz's own model, is coming to.

### We don't scrape a worse copy of something published properly

A patent is not a web page. Neither is a standard, a clinical trial or a court judgment.

### The same thing, recognised on every shelf

Nearly everything worth indexing already has an official reference number. A company has a registration number.

### The shelves grow where people look. Point us at yours

Collections expand toward what readers actually ask about, and because the index is ours, adding to one is a decision we can simply make. If a source you rely on isn't here, tell us — and if the site is yours, you can have it read directly with priority rather than waiting your turn.
