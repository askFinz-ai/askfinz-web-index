# Code repository search

Libraries findable by what they do rather than what they are called, with the docs read alongside the code.

**Canonical page:** [https://askfinz.com/collections/code-repositories](https://askfinz.com/collections/code-repositories)

## Key points

### How it divides

81,941 repositories are filed under Python — 41.5% of those that declare it.

### What you can do with it

Find a library by behaviour — Describe what you need; the package name is what you are missing.

### Filed to answer

Which library does this, in this language, and is anyone still maintaining it?

### Written to

A new record is a newly published repositorie. A revision replaces the text on the record that already exists rather than adding a second one, so the count does not double.

### Where it stops

It does not run anything. This is repositories and their documentation read as text — not a package registry, an installer or a build.
